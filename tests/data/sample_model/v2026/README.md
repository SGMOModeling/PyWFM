# SampleModel v2026

Inputs of the IWFM 2026.0.1848 release SampleModel, used when the loaded DLL
is an IWFM 2026 build (stock 2026.0.1848 or the handle-based 2026.0.1848.rev
build). Changes from the release:

- `Simulation/Simulation_MAIN.IN` is the release's daily main file
  (`Simulation_Daily_MAIN.IN`, 1DAY time step like v2025) with EDT shortened
  from 09/30/2020 to 09/30/2000 (10 water years, the same span as v2025) to
  keep the once-per-session simulation short.
- `Simulation/TSDATA_IN.DSS` is the release's time-series file converted to
  HEC-DSS 7; `Simulation/TSDATA_IN_dss6.DSS` is the release's original. The
  handle-based fork builds read only DSS-7 and the stock DWR DLLs read only
  DSS-6, so the test fixtures copy the matching file into a working copy
  (tests/data/sample_model/.work/). v2025 carries the same pair.
- `Simulation/PreProcessor.bin` was generated by the release's
  PreProcessor_x64.exe from `Preprocessor/`.
- Transport inputs and run scripts are omitted.
